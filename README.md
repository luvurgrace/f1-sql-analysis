## Objective
Analyze Formula 1 history (1950-2026) using SQL and MySQL.

## Dataset
Source:
https://github.com/Arths17/f1-dataset

## Research Questions
1. Most dominant drivers by decade
2. Constructor dominance by decade
3. Season champions
4. Impact of pole position
5. Position gainers
6. Pit stop evolution
7. Reliability trends
8. Tire strategy effectiveness
